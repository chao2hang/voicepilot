# 识别与翻译提供程序契约

当前没有后端协议、服务地址、认证方式或选定厂商。本项目因此**没有虚构 HTTP 实现**，只定义进程内抽象与两个明确标注的开发提供程序。

## 接入边界

- `ISpeechRecognitionProvider.RecognizeAsync` 接收有界、可取消的 `IAsyncEnumerable<PcmFrame>`，输入始终是 16 kHz、单声道、PCM16，通常每块 20 ms。
- 识别实现以 `RecognitionUpdate` 返回临时或最终结果。文本、时间戳和隐私策略属于提供程序实现，不污染采集层。
- `ITranslationProvider.TranslateAsync` 只翻译最终识别结果，按序等待，避免慢网络造成无限请求。临时识别原文可即时显示。
- 语言、术语和 `ProviderOptions` 都是可扩展配置。`ProviderOptions` 的键由未来适配器文档定义，目前为空。
- 每个实现负责超时、取消、重试、流式协议、服务错误映射和限流。不得在音频回调内执行网络请求。
- 若需要令牌，应使用 Windows DPAPI/凭据保管库等安全存储；现有 JSON 设置模型没有任何令牌字段。禁止记录原文、译文、音频、访问令牌或带凭据的 URL。

## 当前实现

| ID | 用途 | 是否真实服务 |
| --- | --- | --- |
| `unconfigured` | 排空有界音频流，允许仅验证采集 | 否，明确显示“仅采集” |
| `simulation` | 产生固定模拟文本，验证 UI、取消和结果顺序 | 否，所有结果带“模拟”标记 |

真实端到端识别和翻译在后端接口确定并提供适配器之前，不属于已验证功能。
