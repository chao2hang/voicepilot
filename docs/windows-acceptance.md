# Windows 11 验收清单

请在受支持的 Windows 11、.NET 10 SDK 和 Windows App SDK 2.7.0 Runtime 上执行。记录机器、OS build、驱动、设备型号、网络环境及应用提交版本。**模拟提供程序不可作为真实识别或翻译验收。**

## 性能和稳定性

在 Release 构建运行：

```powershell
pwsh ./scripts/measure-windows.ps1 -Hours 1
```

脚本每 5 秒记录 CPU、工作集、私有内存、线程/句柄、响应状态及机器信息。选择固定设备，手动开始采集并播放连续测试音频；在界面记录队列、丢弃和“识别时音频年龄”。后者只是识别事件到达时最新采集帧的年龄，**不是对应音频帧的端到端识别延迟**。真实端到端测量需要后端协议提供音频位置/结果关联，或使用带时间标记的测试音频与外部计时。
